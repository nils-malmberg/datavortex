# Phase 3 : Filtrage & Colonnes Calculées

Dépend de Phase 1-2 complétées.

## Tâches Backend
1. Moteur d'évaluation de formules sûr
2. Route appliquer filtres (AND/OR logic)
3. Route créer colonne (évaluer formule pour chaque ligne)
4. Validation formules + colonnes

## Tâches Frontend
1. Filter Builder interface
2. Expression builder (sélection colonnes, opérateurs)
3. Column Creator avec éditeur formule
4. Validation temps réel

## Opérateurs supportés
- Arithmétiques: +, -, *, /, %
- Comparaison: ==, !=, >, <, >=, <=
- Logiques: AND, OR, NOT
- Fonctions: abs, round, sqrt, log, etc
